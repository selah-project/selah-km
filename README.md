# បទគម្ពីរហេព្រើរ (តាណាខ) — ការបកប្រែជាភាសាខ្មែរ

ការបកប្រែជាភាសាខ្មែរនៃព្រះគម្ពីរហេព្រើរ (តាណាខ) — ខម្តងមួយៗ ស្មោះនឹងអក្សរនៃអត្ថបទ។

នេះជា **កៅអីទី ៥៣** នៃគម្រោង Selah — អុជភ្លើងថ្ងៃទី ០១ ខែកញ្ញា ឆ្នាំ ២០២៦ — ហើយជា **កៅអីអូស្ត្រូអាស៊ីអាទិកទីពីរ**៖ វាឡើងបន្ទាប់ពីកៅអីសេប្វាណូ (ទី ៥២) បានអង្គុយ ហើយដើរតាមក្រោយភាសាវៀតណាម។ ភាសាដែលមានអ្នកនិយាយប្រហែល ១៧ លាននាក់ នៅព្រះរាជាណាចក្រកម្ពុជា។ ឃ្លាំងផ្ទុក៖ `selah-km`។

## ភាសាហេព្រើរ — មុនគេ

ការបកប្រែនេះមានវត្តមាន ដើម្បីនាំអ្នកទៅរកភាសាហេព្រើរ — មិនមែនដើម្បីជំនួសវាទេ។ អ្វីដែលត្រូវអានជានិច្ចគឺភាសាហេព្រើរ៖ អក្សររបស់វា សំឡេងរបស់វា សញ្ញារបស់វា។ អត្ថបទខ្មែរនៅខាងក្រោមជាបង្អួច មិនមែនជាអ្នកជំនួសទេ។ នៅកន្លែងណាដែលទាំងពីរបែកគ្នា សេចក្ដីពិតស្ថិតនៅក្នុងភាសាហេព្រើរ។

## ព្រះនាម

នៅកន្លែងដែលព្រះនាមបួនអក្សរឈរ យើងសរសេរ **យ៉ាវេ** — មិនមែនងារ មិនមែនពាក្យសាមញ្ញដែលយកកន្លែងរបស់វាទេ។ យើងមិនសរសេរ **ព្រះយេហូវ៉ា / យេហូវ៉ា** (ទម្រង់កូនកាត់) ឡើយ; យើងមិនដាក់ **ព្រះ** នៅអាសនៈព្រះនាមឡើយ (ពាក្យសាមញ្ញ — វាទ្រទ្រង់ទម្ងន់ជំនឿយ៉ាងធ្ងន់សម្រាប់មនុស្សជាច្រើន ហើយវាឈរនៅជួរឈរសាក្សី មិនមែននៅជួររបស់យើងទេ); ហើយយើងមិនសរសេរ **ព្រះអម្ចាស់** ឡើយ (ងារដែលព្រះគម្ពីរខ្មែរដាក់ជំនួសព្រះនាម — ជាងារ មិនមែនជាឈ្មោះ; ងារលុបព្រះនាមចោល)។ ព្រះនាមនៅតែឈរគ្រប់កន្លែងតាមទម្រង់របស់វា — ដើម្បីឱ្យគេឃើញជានិច្ចថាវាឈរនៅឯណា។

ពាក្យ **ព្រះ** ក៏មិនត្រូវភ្ជាប់ជាបុព្វបទកិត្តិយសទៅលើទម្រង់របស់យើងដែរ៖ **យ៉ាវេ** មិនមែន *ព្រះយ៉ាវេ*; **អេឡូហ៊ីម** មិនមែន *ព្រះអេឡូហ៊ីម*។ ព្រះនាមនៅតែជាឈ្មោះ។

## អាឡេហ្វ-តាវ — ⟨את⟩

នៅក្នុងឃ្លាភាសាខ្មែរ អ្នកនឹងឃើញសញ្ញា **⟨את⟩**។ នៅក្នុងភាសាហេព្រើរ אֵת ជាពាក្យតូចមួយដែលចង្អុលទៅវត្ថុដែលកិរិយាធ្លាក់លើ។ ភាសាខ្មែរគ្មានអ្វីស្មើនឹងវាទេ ហើយការបកប្រែភាគច្រើនទុកវាឱ្យបាត់ដោយស្ងៀមស្ងាត់។ យើងរក្សាវាទុកនៅក្នុងវង់ក្រចកមុំ ដើម្បីឱ្យវាមើលឃើញ — វាជាផ្នែកមួយនៃរចនាសម្ព័ន្ធហេព្រើរ។ នៅកន្លែងណាដែល את ជាសព្វនាម *អ្នក* (H859) វាត្រូវបកប្រែជា **អ្នក** មិនមែនជាសញ្ញាទេ។

## ពាក្យនៅក្នុង ⟨វង់ក្រចកមុំ⟩

វង់ក្រចកមុំក្នុងទម្រង់នេះ ⟨ដូចនេះ⟩ សម្គាល់ពាក្យដែល **មិនមាននៅក្នុងភាសាហេព្រើរ** — ការបន្ថែមដែលឃ្លាភាសាខ្មែរត្រូវការ។ នៅក្នុងវង់ក្រចក — មានតែភាសាខ្មែរប៉ុណ្ណោះ។

## ឈ្មោះ និងងារ

ព្រះនាមហេព្រើរដែលចង្អុលទៅព្រះដ៏វិសុទ្ធ — **អេឡូហ៊ីម**, **អែល**, **អេឡូអះ**, **ស្ហាដាយ**, **អាដូណាយ**, **យ៉ា** — ត្រូវសរសេរតាមសំឡេងរបស់វា។ យើងមិនបញ្ចូលវាទាំងអស់ទៅជាឈ្មោះតែមួយទេ; នីមួយៗទ្រទ្រង់ទម្ងន់ផ្ទាល់ខ្លួន។ ឈ្មោះមនុស្ស និងឈ្មោះទីកន្លែងក៏ដើរតាមទម្រង់ហេព្រើរដែរ៖ អាវរ៉ាហាំ, ម៉ូស្ហេ, យេហូស្ហួ, ស្ហាអ៊ូល, មិតស្រាយិម, ប៉ារ៉ូ, យេរូស្ហាឡាយិម។

## ពាក្យដែលបានដាក់សញ្ញា

- **ហេសែដ** (חֶסֶד) — សេចក្ដីស្រឡាញ់នៃសម្ពន្ធមេត្រីដែលមិនចេះរីងស្ងួត។ មិនត្រឹមតែ "សេចក្ដីមេត្តា" មិនត្រឹមតែ "ព្រះគុណ" ទេ។ គ្មានពាក្យខ្មែរតែមួយណាដែលអាចទ្រទ្រង់វាដោយឯកឯងបានឡើយ។
- **ស្ហេអុល** (שְׁאוֹל) — កន្លែងរបស់មនុស្សស្លាប់ តាមអ្វីដែលភាសាហេព្រើរនិយាយ។ មិនដែលជា "នរក" មិនដែលជា "ស្ថានលោកខាងក្រោម" ឡើយ។
- **ម៉ាស៊ីអះ** (מָשִׁיחַ) — **អ្នកដែលបានចាក់ប្រេងតាំង** — នៅកម្រិតតាណាខ មិនដែលជា "គ្រីស្ទ" ឡើយ។
- **នេហ្វេស្ហ**, **រូអះ**, **កាវ៉ូដ** — បកប្រែតាមកន្លែងរបស់វា (ព្រលឹង ឬជីវិត; វិញ្ញាណ ដង្ហើម ឬខ្យល់; សិរីរុងរឿង ឬទម្ងន់) — មិនចងភ្ជាប់នឹងពាក្យរឹងតែមួយឡើយ។

## ខនីមួយៗនៅក្នុងពន្លឺរបស់ខ្លួន

ខនីមួយៗនិយាយអ្វីដែលវានិយាយនៅកន្លែងរបស់វា — យើងអានវាដោយជំនឿហេព្រើរថា អេឡូហ៊ីមមានតែមួយ។ យើងមិនអូសទេវវិទ្យាជំនាន់ក្រោយថយក្រោយចូលក្នុងអត្ថបទឡើយ; យើងមិនអានទីបញ្ចប់នៃរឿងនៅក្នុងដើមដំបូងឡើយ។

## ទម្រង់ឯកសារ

ខមួយ — ឯកសារមួយ៖ ខខ្លួនឯង និងសេចក្ដីស្មើនៃពាក្យនីមួយៗដែលឈរជាប់នឹងពាក្យហេព្រើររបស់វា — ដើម្បីឱ្យពាក្យហេព្រើរនីមួយៗអានបានទល់មុខនឹងពាក្យខ្មែររបស់វា។
